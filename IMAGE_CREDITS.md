# 🖼️ Créditos das imagens

Todas as imagens adicionadas na versão 2 são de uso livre, com licenças que
permitem uso comercial e não exigem atribuição. Ainda assim, os créditos são
listados abaixo como boa prática.

> **Nota:** o objetivo inicial era usar imagens do
> [Pixabay](https://pixabay.com/images/search/). No ambiente de build utilizado
> o CDN do Pixabay não estava acessível (bloqueio de rede/anti-bot), então
> foram usadas imagens do [Unsplash](https://unsplash.com), que possui uma
> licença equivalente de uso livre. As imagens ficam versionadas na pasta
> `img/`, tornando a aplicação autossuficiente (sem hotlinks que quebram).
